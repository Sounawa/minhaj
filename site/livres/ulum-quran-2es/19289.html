Les sciences du Coran : sources et références des leçons de la deuxième année du cycle collégial traditionnel

Liste des sources et références adoptées pour les leçons de sciences du Coran de la deuxième année du cycle collégial traditionnel ('atīq) ; tirée du Manāhil al-'irfān fī 'ulūm al-Qur'ān de Muḥammad (مُحَمَّدٌ) 'Abd al-'Aẓīm al-Zarqānī.

  • 1. Le Noble Coran, dans la transmission (riwāya (رِوَايَة)) de Warch d’après Nāfi' — l’édition publiée par la fondation Muḥammad (مُحَمَّدٌ) VI pour la publication du Noble Muṣḥaf, ministère marocain des Habous et des Affaires islamiques.
  • 2. al-Itqān fī 'ulūm al-Qur'ān, de 'Abd al-Raḥmān ibn Abī (أَبِي) Bakr Jalāl al-Dīn al-Suyūṭī (mort en 911 H) ; édition critique : Muḥammad (مُحَمَّدٌ) Abū (أَبُو) l-Faḍl Ibrāhīm (إِبْرَاهِيمُ) ; l’Organisme égyptien général du Livre ; 1re édition / 1394 H - 1974 E.C.
  • 3. Aḥkām (أحكام) al-Qur'ān, du cadi Muḥammad (مُحَمَّدٌ) ibn 'Abd Allāh (اللَّه) Abū (أَبُو) Bakr Ibn al-'Arabī al-Ma'āfirī al-Ishbīlī al-Mālikī (mort en 543 H) ; Dār al-Kutub al-'Ilmiyya, Beyrouth, Liban ; 3e édition / 1424 H - 2003 E.C.
  • 4. Aḥkām (أحكام) al-Qur'ān, d’Abū (أَبُو) Muḥammad (مُحَمَّدٌ) 'Abd al-Mun'im ibn 'Abd al-Raḥīm, connu sous le nom d’Ibn al-Faras al-Andalusī (mort en 597 H) ; édition critique : Ṭāhā ibn 'Alī Bū Sirayḥ et autres ; Dār Ibn Ḥazm, Beyrouth, Liban ; 1re édition / 1427 H - 2006 E.C.
  • 5. al-Baḥr al-muḥīṭ fī al-tafsīr, d’Abū (أَبُو) Ḥayyān Muḥammad (مُحَمَّدٌ) ibn Yūsuf (يُوسُفُ) ibn 'Alī ibn Yūsuf (يُوسُفُ) Ibn Ḥayyān Athīr al-Dīn al-Andalusī (mort en 745 H) ; édition critique : Ṣadqī Muḥammad (مُحَمَّدٌ) Jamīl ; Dār al-Fikr, Beyrouth ; édition / 1420 H.
  • 6. al-Burhān fī 'ulūm al-Qur'ān, d’Abū (أَبُو) 'Abd Allāh (اللَّه) Badr al-Dīn Muḥammad (مُحَمَّدٌ) ibn 'Abd Allāh (اللَّه) ibn Bahādur al-Zarkashī (mort en 794 H) ; édition critique : Muḥammad (مُحَمَّدٌ) Abū (أَبُو) l-Faḍl Ibrāhīm (إِبْرَاهِيمُ) ; 1re édition / 1376 H - 1957 E.C. ; Dār Iḥyā' al-Kutub al-'Arabiyya, 'Īsā al-Bābī al-Ḥalabī et ses associés.
  • 7. Ta'wīl mushkil al-Qur'ān, d’Abū (أَبُو) Muḥammad (مُحَمَّدٌ) 'Abd Allāh (اللَّه) ibn Muslim ibn Qutayba al-Dīnawarī (mort en 276 H) ; édition critique : al-Sayyid Aḥmad (أَحْمَد) Ṣaqr ; al-Maktaba al-'Ilmiyya, Liban.
  • 8. al-Taḥrīr wa-l-tanwīr — “Libération du sens droit et illumination de l’esprit nouveau, par le commentaire du Livre glorieux” —, d’Ibn 'Āshūr ; la Maison tunisienne d’édition, Tunis ; 1984 E.C.
  • 9. Tuḥfat al-aḥwadhī bi-sharḥ Jāmi' al-Tirmidhī, d’Abū (أَبُو) l-'Alā' Muḥammad (مُحَمَّدٌ) 'Abd al-Raḥmān ibn 'Abd al-Raḥīm al-Mubārakfūrī (mort en 1353 H) ; Dār al-Kutub al-'Ilmiyya, Beyrouth.
  • 10. Talkhīṣ al-ḥabīr fī takhrīj aḥādīth (أَحَادِيث) al-Rāfi'ī al-kabīr, d’Abū (أَبُو) l-Faḍl Aḥmad (أَحْمَد) ibn 'Alī ibn Muḥammad (مُحَمَّدٌ) ibn Aḥmad (أَحْمَد) Ibn Ḥajar al-'Asqalānī (mort en 852 H) ; Dār al-Kutub al-'Ilmiyya ; 1re édition / 1419 H - 1989 E.C.
  • 11. Tafsīr (تَفْسِير) al-Qur'ān al-'aẓīm, d’Abū (أَبُو) l-Fidā' Ismā'īl ibn 'Umar Ibn Kathīr al-Qurashī al-Baṣrī puis al-Dimashqī (mort en 774 H) ; édition critique : Sāmī ibn Muḥammad (مُحَمَّدٌ) Salāma ; Dār Ṭayba ; 2e édition / 1420 H - 1999 E.C.
  • 12. al-Tashīl li-'ulūm al-tanzīl, d’Abū (أَبُو) l-Qāsim Muḥammad (مُحَمَّدٌ) ibn Aḥmad (أَحْمَد) ibn Muḥammad (مُحَمَّدٌ) ibn 'Abd Allāh (اللَّه) Ibn Juzayy al-Kalbī al-Gharnāṭī (mort en 741 H) ; édition critique : Dr 'Abd Allāh (اللَّه) al-Khālidī ; Dār al-Arqam ibn Abī (أَبِي) al-Arqam, Beyrouth ; 1re édition / 1416 H.
  • 13. Jāmi' al-bayān fī ta'wīl al-Qur'ān, de Muḥammad (مُحَمَّدٌ) ibn Jarīr ibn Yazīd ibn Kathīr ibn Ghālib al-Āmulī, Abū (أَبُو) Ja'far al-Ṭabarī (mort en 310 H) ; édition critique : Aḥmad (أَحْمَد) Muḥammad (مُحَمَّدٌ) Shākir ; Mu'assasat al-Risāla ; 1re édition / 1420 H - 2000 E.C.
  • 14. al-Jāmi' al-musnad al-ṣaḥīḥ al-mukhtaṣar min umūr rasūl (رَسُول) Allāh (اللَّه) ﷺ wa-sunanihi wa-ayyāmihi, de Muḥammad (مُحَمَّدٌ) ibn Ismā'īl Abū (أَبُو) 'Abd Allāh (اللَّه) al-Bukhārī al-Ju'fī ; édition critique : Muḥammad (مُحَمَّدٌ) Zuhayr ibn Nāṣir al-Nāṣir ; Dār Ṭawq al-Najāt ; 1re édition / 1422 H.
  • 15. al-Jāmi' li-aḥkām al-Qur'ān, wa-l-mubayyin limā taḍammana min al-sunna wa-āy al-furqān (الْفُرْقَانُ), d’Abū (أَبُو) 'Abd Allāh (اللَّه) Muḥammad (مُحَمَّدٌ) ibn Aḥmad (أَحْمَد) ibn Abī (أَبِي) Bakr ibn Farḥ al-Anṣārī al-Khazrajī Shams al-Dīn al-Qurṭubī (mort en 671 H) ; édition critique : Aḥmad (أَحْمَد) al-Bardūnī et Ibrāhīm (إِبْرَاهِيمُ) Aṭfīyash ; Dār al-Kutub al-Miṣriyya, Le Caire ; 2e édition / 1384 H.
  • 16. Jawāhir al-Qur'ān, d’Abū (أَبُو) Ḥāmid Muḥammad (مُحَمَّدٌ) ibn Muḥammad (مُحَمَّدٌ) al-Ghazālī al-Ṭūsī (mort en 505 H) ; édition critique : Dr le cheikh Muḥammad (مُحَمَّدٌ) Rashīd Riḍā al-Qabbānī ; Dār Iḥyā' al-'Ulūm, Beyrouth ; 2e édition / 1406 H - 1986 E.C.
  • 17. al-Muḥarrar al-wajīz fī tafsīr (تَفْسِير) al-kitāb al-'azīz, d’Abū (أَبُو) Muḥammad (مُحَمَّدٌ) 'Abd al-Ḥaqq ibn Ghālib ibn 'Abd al-Raḥmān ibn Tammām Ibn 'Aṭiyya al-Andalusī al-Maḥāribī (mort en 542 H) ; édition critique : 'Abd al-Salām 'Abd al-Shāfī Muḥammad (مُحَمَّدٌ) ; Dār al-Kutub al-'Ilmiyya, Beyrouth ; 1re édition / 1422 H.
  • 18. al-Mudawwana al-kubrā, de l’Imām (إِمَام) Mālik (مَالِك) ibn Anas ibn Mālik (مَالِك) ibn 'Āmir al-Aṣbaḥī al-Madanī (mort en 179 H), dans la transmission de Saḥnūn d’après Abū (أَبُو) l-Qāsim ; Dār al-Kutub al-'Ilmiyya ; 1re édition / 1415 H - 1994 E.C.
  • 19. al-Mustadrak 'alā al-ṣaḥīḥayn, d’Abū (أَبُو) 'Abd Allāh (اللَّه) al-Ḥākim Muḥammad (مُحَمَّدٌ) ibn 'Abd Allāh (اللَّه) ibn Muḥammad (مُحَمَّدٌ) ibn Ḥamduwayh ibn Nu'aym ibn al-Ḥakam al-Ḍabbī al-Ṭahmānī al-Naysābūrī, connu sous le nom d’Ibn al-Bayyi' (mort en 405 H) ; édition critique : Muṣṭafā 'Abd al-Qādir 'Aṭā ; Dār al-Kutub al-'Ilmiyya, Beyrouth ; 1re édition / 1411 H - 1990 E.C.
  • 20. Musnad al-Imām Aḥmad (أَحْمَد) ibn Ḥanbal, d’Abū (أَبُو) 'Abd Allāh (اللَّه) Aḥmad (أَحْمَد) ibn Muḥammad (مُحَمَّدٌ) ibn Ḥanbal ibn Hilāl ibn Asad al-Shaybānī (mort en 241 H) ; édition critique : Aḥmad (أَحْمَد) Muḥammad (مُحَمَّدٌ) Shākir ; Dār al-Ḥadīth, Le Caire ; 1re édition / 1416 H - 1995 E.C.
  • 21. al-Musnad al-ṣaḥīḥ al-mukhtaṣar bi-naql al-'adl 'an al-'adl 'an rasūl (رَسُول) Allāh (اللَّه) ﷺ, de Muslim ibn al-Ḥajjāj Abū (أَبُو) l-Ḥasan al-Qushayrī al-Naysābūrī (mort en 261 H) ; édition critique : Muḥammad (مُحَمَّدٌ) Fu'ād 'Abd al-Bāqī ; Dār Iḥyā' al-Turāth al-'Arabī, Beyrouth.
  • 22. Mafātīḥ al-ghayb, dit al-Tafsīr al-kabīr, d’Abū (أَبُو) 'Abd Allāh (اللَّه) Muḥammad (مُحَمَّدٌ) ibn 'Umar ibn al-Ḥasan ibn al-Ḥusayn al-Taymī al-Rāzī, surnommé Fakhr al-Dīn al-Rāzī, prédicateur (khaṭīb) de Rayy (mort en 606 H) ; Dār Iḥyā' al-Turāth al-'Arabī, Beyrouth ; 3e édition / 1420 H.
  • 23. La Muqaddima d’Ibn Khaldūn, de Walī al-Dīn 'Abd al-Raḥmān ibn Muḥammad (مُحَمَّدٌ) Ibn Khaldūn (mort en 808 H) ; édition critique : 'Abd Allāh (اللَّه) Muḥammad (مُحَمَّدٌ) al-Darwīsh ; Dār Ya'rūb ; 1re édition / 2004 E.C.
  • 24. Manāhil al-'irfān fī 'ulūm al-Qur'ān, de Muḥammad (مُحَمَّدٌ) 'Abd al-'Aẓīm al-Zarqānī (mort en 1367 H) ; Imprimerie 'Īsā al-Bābī al-Ḥalabī et ses associés ; 3e édition / sans date.
  • 25. al-Muwāfaqāt, d’Ibrāhīm (إِبْرَاهِيمُ) ibn Mūsā (مُوسَى) ibn Muḥammad (مُحَمَّدٌ) al-Lakhmī al-Gharnāṭī, célèbre sous le nom d’al-Shāṭibī (mort en 790 H) ; Dār Ibn 'Affān ; 1re édition / 1417 H - 1997 E.C.
  • 26. al-Nukat wa-l-'uyūn, d’Abū (أَبُو) l-Ḥasan 'Alī ibn Muḥammad (مُحَمَّدٌ) ibn Muḥammad (مُحَمَّدٌ) ibn Ḥabīb al-Baṣrī al-Baghdādī, célèbre sous le nom d’al-Māwardī (mort en 450 H) ; édition critique : al-Sayyid ibn 'Abd al-Maqṣūd ibn 'Abd al-Raḥīm ; Dār al-Kutub al-'Ilmiyya, Beyrouth, Liban.
  • 27. Ṣaḥīḥ Ibn Ḥibbān, classé par Ibn Bulbān, de Muḥammad (مُحَمَّدٌ) ibn Ḥibbān ibn Aḥmad (أَحْمَد) ibn Ḥibbān ibn Mu'ādh ibn Ma'bad al-Tamīmī, Abū (أَبُو) Ḥātim, al-Dārimī, al-Bustī (mort en 354 H) ; édition critique : Shu'ayb al-Arna'ūṭ ; Mu'assasat al-Risāla, Beyrouth ; édition / 1414 H - 1993 E.C.
  • 28. Sunan Abī (أَبِي) Dāwūd (دَاوُدُ), d’Abū (أَبُو) Dāwūd (دَاوُدُ) Sulaymān (سُلَيْمَانُ) ibn al-Ash'ath ibn Isḥāq (إِسْحَاقُ) ibn Bashīr ibn Shaddād ibn 'Amr al-Azdī al-Sijistānī (mort en 275 H) ; édition critique : Muḥammad (مُحَمَّدٌ) Muḥyī al-Dīn 'Abd al-Ḥamīd ; al-Maktaba al-'Aṣriyya, Saïda - Beyrouth.
  • 29. Sunan Ibn Māja, d’Ibn Māja, Abū (أَبُو) 'Abd Allāh (اللَّه) Muḥammad (مُحَمَّدٌ) ibn Yazīd al-Qazwīnī (mort en 273 H) ; édition critique : Shu'ayb al-Arna'ūṭ, 'Ādil Murshid, Muḥammad (مُحَمَّدٌ) Kāmil Qara Balallī et 'Abd al-Laṭīf Ḥarz Allāh (اللَّه) ; Dār al-Risāla al-'Ālamiyya ; 1re édition / 1430 H - 2009 E.C.
  • 30. Sunan al-Tirmidhī, de Muḥammad (مُحَمَّدٌ) ibn 'Īsā ibn Sawra ibn Mūsā (مُوسَى) ibn al-Ḍaḥḥāk, al-Tirmidhī, Abū (أَبُو) 'Īsā (mort en 279 H) ; édition critique et annotation : Aḥmad (أَحْمَد) Muḥammad (مُحَمَّدٌ) Shākir, Muḥammad (مُحَمَّدٌ) Fu'ād 'Abd al-Bāqī et Ibrāhīm (إِبْرَاهِيمُ) 'Aṭwa 'Awḍ ; société Maktabat wa-Maṭba'at Muṣṭafā al-Bābī al-Ḥalabī, Égypte ; 2e édition / 1395 H.
