Les sciences du Coran : sources et références des leçons de la deuxième année du cycle collégial traditionnel

Liste des sources et références adoptées pour les leçons de sciences du Coran de la deuxième année du cycle collégial traditionnel (ʿatīq) ; tirée du Manāhil al-ʿirfān fī ʿulūm al-Qurʾān de Muḥammad ʿAbd al-ʿAẓīm al-Zarqānī.

  • 1. Le Noble Coran, dans la transmission (riwāya) de Warš d’après Nāfiʿ — l’édition publiée par la fondation Muḥammad VI pour la publication du Noble Muṣḥaf, ministère marocain des Habous et des Affaires islamiques.
  • 2. al-Itqān fī ʿulūm al-Qurʾān, de ʿAbd al-Raḥmān ibn Abī Bakr Jalāl al-Dīn al-Suyūṭī (mort en 911 H) ; édition critique : Muḥammad Abū l-Faḍl Ibrāhīm ; l’Organisme égyptien général du Livre ; 1re édition / 1394 H - 1974 E.C.
  • 3. Aḥkām al-Qurʾān, du cadi Muḥammad ibn ʿAbd Allāh Abū Bakr Ibn al-ʿArabī al-Maʿāfirī al-Ishbīlī al-Mālikī (mort en 543 H) ; Dār al-Kutub al-ʿIlmiyya, Beyrouth, Liban ; 3e édition / 1424 H - 2003 E.C.
  • 4. Aḥkām al-Qurʾān, d’Abū Muḥammad ʿAbd al-Munʿim ibn ʿAbd al-Raḥīm, connu sous le nom d’Ibn al-Faras al-Andalusī (mort en 597 H) ; édition critique : Ṭāhā ibn ʿAlī Bū Sirayḥ et autres ; Dār Ibn Ḥazm, Beyrouth, Liban ; 1re édition / 1427 H - 2006 E.C.
  • 5. al-Baḥr al-muḥīṭ fī al-tafsīr, d’Abū Ḥayyān Muḥammad ibn Yūsuf ibn ʿAlī ibn Yūsuf Ibn Ḥayyān Athīr al-Dīn al-Andalusī (mort en 745 H) ; édition critique : Ṣadqī Muḥammad Jamīl ; Dār al-Fikr, Beyrouth ; édition / 1420 H.
  • 6. al-Burhān fī ʿulūm al-Qurʾān, d’Abū ʿAbd Allāh Badr al-Dīn Muḥammad ibn ʿAbd Allāh ibn Bahādur al-Zarkashī (mort en 794 H) ; édition critique : Muḥammad Abū l-Faḍl Ibrāhīm ; 1re édition / 1376 H - 1957 E.C. ; Dār Iḥyāʾ al-Kutub al-ʿArabiyya, ʿĪsā al-Bābī al-Ḥalabī et ses associés.
  • 7. Taʾwīl mushkil al-Qurʾān, d’Abū Muḥammad ʿAbd Allāh ibn Muslim ibn Qutayba al-Dīnawarī (mort en 276 H) ; édition critique : al-Sayyid Aḥmad Ṣaqr ; al-Maktaba al-ʿIlmiyya, Liban.
  • 8. al-Taḥrīr wa-l-tanwīr — “Libération du sens droit et illumination de l’esprit nouveau, par le commentaire du Livre glorieux” —, d’Ibn ʿĀshūr ; la Maison tunisienne d’édition, Tunis ; 1984 E.C.
  • 9. Tuḥfat al-aḥwadhī bi-sharḥ Jāmiʿ al-Tirmidhī, d’Abū l-ʿAlāʾ Muḥammad ʿAbd al-Raḥmān ibn ʿAbd al-Raḥīm al-Mubārakfūrī (mort en 1353 H) ; Dār al-Kutub al-ʿIlmiyya, Beyrouth.
  • 10. Talkhīṣ al-ḥabīr fī takhrīj aḥādīth al-Rāfiʿī al-kabīr, d’Abū l-Faḍl Aḥmad ibn ʿAlī ibn Muḥammad ibn Aḥmad Ibn Ḥajar al-ʿAsqalānī (mort en 852 H) ; Dār al-Kutub al-ʿIlmiyya ; 1re édition / 1419 H - 1989 E.C.
  • 11. Tafsīr al-Qurʾān al-ʿaẓīm, d’Abū l-Fidāʾ Ismāʿīl ibn ʿUmar Ibn Kathīr al-Qurashī al-Baṣrī puis al-Dimashqī (mort en 774 H) ; édition critique : Sāmī ibn Muḥammad Salāma ; Dār Ṭayba ; 2e édition / 1420 H - 1999 E.C.
  • 12. al-Tashīl li-ʿulūm al-tanzīl, d’Abū l-Qāsim Muḥammad ibn Aḥmad ibn Muḥammad ibn ʿAbd Allāh Ibn Juzayy al-Kalbī al-Gharnāṭī (mort en 741 H) ; édition critique : Dr ʿAbd Allāh al-Khālidī ; Dār al-Arqam ibn Abī al-Arqam, Beyrouth ; 1re édition / 1416 H.
  • 13. Jāmiʿ al-bayān fī taʾwīl al-Qurʾān, de Muḥammad ibn Jarīr ibn Yazīd ibn Kathīr ibn Ghālib al-Āmulī, Abū Jaʿfar al-Ṭabarī (mort en 310 H) ; édition critique : Aḥmad Muḥammad Shākir ; Muʾassasat al-Risāla ; 1re édition / 1420 H - 2000 E.C.
  • 14. al-Jāmiʿ al-musnad al-ṣaḥīḥ al-mukhtaṣar min umūr rasūl Allāh ﷺ wa-sunanihi wa-ayyāmihi, de Muḥammad ibn Ismāʿīl Abū ʿAbd Allāh al-Bukhārī al-Juʿfī ; édition critique : Muḥammad Zuhayr ibn Nāṣir al-Nāṣir ; Dār Ṭawq al-Najāt ; 1re édition / 1422 H.
  • 15. al-Jāmiʿ li-aḥkām al-Qurʾān, wa-l-mubayyin limā taḍammana min al-sunna wa-āy al-furqān, d’Abū ʿAbd Allāh Muḥammad ibn Aḥmad ibn Abī Bakr ibn Farḥ al-Anṣārī al-Khazrajī Shams al-Dīn al-Qurṭubī (mort en 671 H) ; édition critique : Aḥmad al-Bardūnī et Ibrāhīm Aṭfīyash ; Dār al-Kutub al-Miṣriyya, Le Caire ; 2e édition / 1384 H.
  • 16. Jawāhir al-Qurʾān, d’Abū Ḥāmid Muḥammad ibn Muḥammad al-Ghazālī al-Ṭūsī (mort en 505 H) ; édition critique : Dr le cheikh Muḥammad Rashīd Riḍā al-Qabbānī ; Dār Iḥyāʾ al-ʿUlūm, Beyrouth ; 2e édition / 1406 H - 1986 E.C.
  • 17. al-Muḥarrar al-wajīz fī tafsīr al-kitāb al-ʿazīz, d’Abū Muḥammad ʿAbd al-Ḥaqq ibn Ghālib ibn ʿAbd al-Raḥmān ibn Tammām Ibn ʿAṭiyya al-Andalusī al-Maḥāribī (mort en 542 H) ; édition critique : ʿAbd al-Salām ʿAbd al-Shāfī Muḥammad ; Dār al-Kutub al-ʿIlmiyya, Beyrouth ; 1re édition / 1422 H.
  • 18. al-Mudawwana al-kubrā, de l’Imām Mālik ibn Anas ibn Mālik ibn ʿĀmir al-Aṣbaḥī al-Madanī (mort en 179 H), dans la transmission de Saḥnūn d’après Abū l-Qāsim ; Dār al-Kutub al-ʿIlmiyya ; 1re édition / 1415 H - 1994 E.C.
  • 19. al-Mustadrak ʿalā al-ṣaḥīḥayn, d’Abū ʿAbd Allāh al-Ḥākim Muḥammad ibn ʿAbd Allāh ibn Muḥammad ibn Ḥamduwayh ibn Nuʿaym ibn al-Ḥakam al-Ḍabbī al-Ṭahmānī al-Naysābūrī, connu sous le nom d’Ibn al-Bayyiʿ (mort en 405 H) ; édition critique : Muṣṭafā ʿAbd al-Qādir ʿAṭā ; Dār al-Kutub al-ʿIlmiyya, Beyrouth ; 1re édition / 1411 H - 1990 E.C.
  • 20. Musnad al-Imām Aḥmad ibn Ḥanbal, d’Abū ʿAbd Allāh Aḥmad ibn Muḥammad ibn Ḥanbal ibn Hilāl ibn Asad al-Shaybānī (mort en 241 H) ; édition critique : Aḥmad Muḥammad Shākir ; Dār al-Ḥadīth, Le Caire ; 1re édition / 1416 H - 1995 E.C.
  • 21. al-Musnad al-ṣaḥīḥ al-mukhtaṣar bi-naql al-ʿadl ʿan al-ʿadl ʿan rasūl Allāh ﷺ, de Muslim ibn al-Ḥajjāj Abū l-Ḥasan al-Qushayrī al-Naysābūrī (mort en 261 H) ; édition critique : Muḥammad Fuʾād ʿAbd al-Bāqī ; Dār Iḥyāʾ al-Turāth al-ʿArabī, Beyrouth.
  • 22. Mafātīḥ al-ghayb, dit al-Tafsīr al-kabīr, d’Abū ʿAbd Allāh Muḥammad ibn ʿUmar ibn al-Ḥasan ibn al-Ḥusayn al-Taymī al-Rāzī, surnommé Fakhr al-Dīn al-Rāzī, prédicateur (khaṭīb) de Rayy (mort en 606 H) ; Dār Iḥyāʾ al-Turāth al-ʿArabī, Beyrouth ; 3e édition / 1420 H.
  • 23. La Muqaddima d’Ibn Khaldūn, de Walī al-Dīn ʿAbd al-Raḥmān ibn Muḥammad Ibn Khaldūn (mort en 808 H) ; édition critique : ʿAbd Allāh Muḥammad al-Darwīsh ; Dār Yaʿrūb ; 1re édition / 2004 E.C.
  • 24. Manāhil al-ʿirfān fī ʿulūm al-Qurʾān, de Muḥammad ʿAbd al-ʿAẓīm al-Zarqānī (mort en 1367 H) ; Imprimerie ʿĪsā al-Bābī al-Ḥalabī et ses associés ; 3e édition / sans date.
  • 25. al-Muwāfaqāt, d’Ibrāhīm ibn Mūsā ibn Muḥammad al-Lakhmī al-Gharnāṭī, célèbre sous le nom d’al-Shāṭibī (mort en 790 H) ; Dār Ibn ʿAffān ; 1re édition / 1417 H - 1997 E.C.
  • 26. al-Nukat wa-l-ʿuyūn, d’Abū l-Ḥasan ʿAlī ibn Muḥammad ibn Muḥammad ibn Ḥabīb al-Baṣrī al-Baghdādī, célèbre sous le nom d’al-Māwardī (mort en 450 H) ; édition critique : al-Sayyid ibn ʿAbd al-Maqṣūd ibn ʿAbd al-Raḥīm ; Dār al-Kutub al-ʿIlmiyya, Beyrouth, Liban.
  • 27. Ṣaḥīḥ Ibn Ḥibbān, classé par Ibn Bulbān, de Muḥammad ibn Ḥibbān ibn Aḥmad ibn Ḥibbān ibn Muʿādh ibn Maʿbad al-Tamīmī, Abū Ḥātim, al-Dārimī, al-Bustī (mort en 354 H) ; édition critique : Shuʿayb al-Arnaʾūṭ ; Muʾassasat al-Risāla, Beyrouth ; édition / 1414 H - 1993 E.C.
  • 28. Sunan Abī Dāwūd, d’Abū Dāwūd Sulaymān ibn al-Ashʿath ibn Isḥāq ibn Bashīr ibn Shaddād ibn ʿAmr al-Azdī al-Sijistānī (mort en 275 H) ; édition critique : Muḥammad Muḥyī al-Dīn ʿAbd al-Ḥamīd ; al-Maktaba al-ʿAṣriyya, Saïda - Beyrouth.
  • 29. Sunan Ibn Māja, d’Ibn Māja, Abū ʿAbd Allāh Muḥammad ibn Yazīd al-Qazwīnī (mort en 273 H) ; édition critique : Shuʿayb al-Arnaʾūṭ, ʿĀdil Murshid, Muḥammad Kāmil Qara Balallī et ʿAbd al-Laṭīf Ḥarz Allāh ; Dār al-Risāla al-ʿĀlamiyya ; 1re édition / 1430 H - 2009 E.C.
  • 30. Sunan al-Tirmidhī, de Muḥammad ibn ʿĪsā ibn Sawra ibn Mūsā ibn al-Ḍaḥḥāk, al-Tirmidhī, Abū ʿĪsā (mort en 279 H) ; édition critique et annotation : Aḥmad Muḥammad Shākir, Muḥammad Fuʾād ʿAbd al-Bāqī et Ibrāhīm ʿAṭwa ʿAwḍ ; société Maktabat wa-Maṭbaʿat Muṣṭafā al-Bābī al-Ḥalabī, Égypte ; 2e édition / 1395 H.
