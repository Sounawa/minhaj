Les sciences du Coran : sources et références adoptées dans le livre de sciences du Coran de la première année du cycle collégial traditionnel

Liste des sources et références citées dans le livre de sciences du Coran prescrit aux élèves de la première année du cycle collégial traditionnel (ʿatīq).

  • 1. Le Noble Coran, dans la transmission (riwāya (رِوَايَة)) de Warch d’après Nāfiʿ, par la voie d’al-Azraq — le muṣḥaf muḥammadien publié par la fondation Muḥammad (مُحَمَّدٌ) VI pour la publication du Noble Coran.
  • 2. Iʿjāz al-Qurʾān (L’inimitabilité du Coran) — auteur : Abū (أَبُو) Bakr al-Bāqillānī Muḥammad (مُحَمَّدٌ) ibn al-Ṭayyib ; éditeur scientifique : al-Sayyid Aḥmad (أَحْمَد) Ṣaqr ; maison d’édition : Dār al-Maʿārif, Égypte ; 5e édition / 1997 E.C.
  • 3. Al-Itqān fī ʿulūm al-Qurʾān — auteur : Jalāl al-Dīn al-Suyūṭī ; édition : Saʿīd al-Mandūb ; Dār al-Fikr, Liban ; 1re édition / 1416 H - 1996 E.C.
  • 4. Asbāb (أسباب) nuzūl al-Qurʾān — auteur : Abū (أَبُو) l-Ḥasan ʿAlī ibn Aḥmad (أَحْمَد) ibn Muḥammad (مُحَمَّدٌ) ibn ʿAlī al-Wāḥidī al-Nīsābūrī al-Chāfiʿī ; édition : ʿIṣām ibn ʿAbd al-Muḥsin al-Ḥumaydān ; Dār al-Iṣlāḥ, Dammām ; 2e édition / 1412 H - 1992 E.C.
  • 5. Al-Burhān fī ʿulūm al-Qurʾān — auteur : Muḥammad (مُحَمَّدٌ) ibn ʿAbd Allāh (اللَّه) al-Zarkachī Badr al-Dīn ; édition : Abū (أَبُو) l-Faḍl al-Dimyāṭī ; Dār al-Ḥadīth ; 1427 H - 2006 E.C.
  • 6. Al-Tibyān fī ādāb ḥamalat al-Qurʾān — auteur : Yaḥyā (يَحْيَى) ibn Charaf al-Dīn al-Nawawī ; édition : Muḥammad (مُحَمَّدٌ) al-Ḥijjār ; 3e édition / 1414 H - 1994 E.C. ; Dār Ibn Ḥazm, Beyrouth, Liban.
  • 7. Tanbīh al-ʿaṭchān ʿalā mawrid al-ẓamʾān — auteur : Abū (أَبُو) ʿAlī Ḥusayn ibn ʿAlī ibn Ṭalḥa al-Rajarājī al-Chūchāwī ; édition : Muḥammad (مُحَمَّدٌ) Sālim Ḥarcha ; mémoire présenté en vue de l’obtention de la licence élevée (« master ») en études coraniques — université d’al-Marqab, faculté des lettres et des sciences, Tarhūna, Libye.
  • 8. Al-Jāmiʿ li-aḥkām al-Qurʾān wa-l-mubayyin limā taḍammanahu min al-sunna wa-āy al-furqān (الْفُرْقَانُ) — auteur : Abū (أَبُو) ʿAbd Allāh (اللَّه) Muḥammad (مُحَمَّدٌ) ibn Aḥmad (أَحْمَد) ibn Abī (أَبِي) Bakr ibn Farḥ al-Anṣārī al-Khazrajī al-Qurṭubī ; édition : Aḥmad (أَحْمَد) al-Bardūnī et Ibrāhīm (إِبْرَاهِيمُ) Aṭfīch ; Dār al-Kutub al-Miṣriyya, Le Caire ; 2e édition / 1438 H.
  • 9. Al-Jāmiʿ al-musnad al-ṣaḥīḥ al-mukhtaṣar min umūr rasūl (رَسُول) Allāh (اللَّه) — que Dieu prie sur lui et le salue — wa-sunanihi wa-ayyāmihi (le Ṣaḥīḥ d’al-Bukhārī) — auteur : Muḥammad (مُحَمَّدٌ) ibn Ismāʿīl al-Bukhārī ; édition : Muḥammad (مُحَمَّدٌ) Zuhayr ibn Nāṣir al-Nāṣir ; maison d’édition : Ṭawq al-Najāt ; 1re édition / 1422 H.
  • 10. Al-Jāmiʿ al-musnad al-ṣaḥīḥ al-mukhtaṣar bin-naql al-ʿadl ʿan al-ʿadl ʿan rasūl (رَسُول) Allāh (اللَّه) — que Dieu prie sur lui et le salue — auteur : Muslim ibn al-Ḥajjāj al-Qushayrī al-Nīsābūrī ; édition : Muḥammad (مُحَمَّدٌ) Fuʾād ʿAbd al-Bāqī ; Dār Iḥyāʾ al-Turāth al-ʿArabī, Beyrouth.
  • 11. Al-Sunan — auteur : Muḥammad (مُحَمَّدٌ) ibn ʿĪsā ibn Sūra ibn Mūsā (مُوسَى) ibn al-Ḍaḥḥāk al-Tirmidhī ; édition : Aḥmad (أَحْمَد) Muḥammad (مُحَمَّدٌ) Chākir (t. 1-2), Muḥammad (مُحَمَّدٌ) Fuʾād ʿAbd al-Bāqī (t. 3) et Ibrāhīm (إِبْرَاهِيمُ) ʿAṭwa ʿAwḍ (t. 4-5) ; maison d’édition : Muṣṭafā al-Bābī al-Ḥalabī ; 2e édition / 1395 H - 1975 E.C.
  • 12. Al-Sunan — auteur : Abū (أَبُو) Dāwūd (دَاوُدُ) Sulaymān (سُلَيْمَانُ) ibn al-Achʿath ibn Isḥāq (إِسْحَاقُ) ibn Bachīr ibn Chaddād ibn ʿAmr al-Azdī al-Sijistānī ; édition : Muḥammad (مُحَمَّدٌ) Muḥyī l-Dīn ʿAbd al-Ḥamīd ; maison d’édition : al-Maktaba al-ʿAṣriyya, Saïda - Beyrouth.
  • 13. Al-Sunan al-kubrā — auteur : Abū (أَبُو) ʿAbd al-Raḥmān Aḥmad (أَحْمَد) ibn Chuʿayb ibn ʿAlī al-Khurāsānī al-Nasāʾī ; édition : Ḥasan ʿAbd al-Munʿim Chalabī ; maison d’édition : Muʾassasat al-Risāla, Beyrouth ; 1re édition / 1427 H - 2001 E.C.
  • 14. Chuʿab al-īmān — auteur : Abū (أَبُو) Bakr Aḥmad (أَحْمَد) ibn al-Ḥusayn al-Bayhaqī ; édition : Muḥammad (مُحَمَّدٌ) al-Saʿīd Basyūnī Zaghlūl ; Dār al-Kutub al-ʿIlmiyya, Beyrouth ; 1re édition / 1410 H.
  • 15. Al-Muḥarrar al-wajīz fī tafsīr (تَفْسِير) al-kitāb al-ʿazīz — auteur : Abū (أَبُو) Muḥammad (مُحَمَّدٌ) ʿAbd al-Ḥaqq ibn Ghālib ibn ʿAbd al-Raḥmān ibn Tammām ibn ʿAṭiyya al-Andalusī al-Maḥāribī ; édition : ʿAbd al-Salām ʿAbd al-Chāfī Muḥammad (مُحَمَّدٌ) ; Dār al-Kutub al-ʿIlmiyya ; 1re édition / 1422 H.
  • 16. Al-Muḥkam fī naqṭ al-maṣāḥif — d’Abū (أَبُو) ʿAmr ʿUthmān ibn Saʿīd al-Dānī ; édition : Dr ʿIzzat Ḥasan ; Dār al-Fikr, Damas ; 2e édition / 1407 H.
  • 17. Al-Muqniʾ fī rasm maṣāḥif al-amṣār, avec le Livre du pointage (al-Naqṭ) — auteur : ʿUthmān ibn Saʿīd al-Dānī ; édition : Muḥammad (مُحَمَّدٌ) al-Ṣādiq Qamḥāwī ; maison d’édition : Maktabat al-Kulliyyāt al-Azhariyya, Le Caire, sans édition ni date.
  • 18. Musnad al-imām Aḥmad (أَحْمَد) ibn Ḥanbal — auteur : Abū (أَبُو) ʿAbd Allāh (اللَّه) Aḥmad (أَحْمَد) ibn Muḥammad (مُحَمَّدٌ) ibn Ḥanbal al-Chaybanī ; édition : Aḥmad (أَحْمَد) Muḥammad (مُحَمَّدٌ) Chākir ; Dār al-Ḥadīth, Le Caire ; 1re édition / 1419 H - 1995 E.C.
  • 19. Al-Manāhil al-ʿirfān fī ʿulūm al-Qurʾān — auteur : Muḥammad (مُحَمَّدٌ) ʿAbd al-ʿAẓīm al-Zarqānī ; maison d’édition : al-Maktaba al-ʿAṣriyya, Beyrouth, Liban ; sans édition, 1433 H - 2012 E.C.
  • 20. Al-Mustadrak ʿalā l-ṣaḥīḥayn — auteur : Abū (أَبُو) ʿAbd Allāh (اللَّه) ibn Muḥammad (مُحَمَّدٌ) ibn Ḥamduwayh al-Nīsābūrī ; édition : Abū (أَبُو) ʿAbd al-Raḥmān Muqbil ibn Hādī al-Wādiʿī ; maison d’édition : Dār al-Ḥaramayn, Le Caire, Égypte ; 1417 H - 1997 E.C.
  • 21. Al-Nabaʾ al-ʿaẓīm : naẓarāt jadīda fī l-Qurʾān al-karīm — auteur : Muḥammad (مُحَمَّدٌ) ibn ʿAbd Allāh (اللَّه) Darāz ; soigné et muni du contrôle des ḥadīths par ʿAbd al-Ḥamīd al-Dakhkhakhnī ; maison d’édition : Dār Ṭayba ; 1re édition / 1417 H - 1997 E.C.
